# The X-Ray — interface contract

Three parts of this film are built by three people at once, so this file is the
seam, not a description. It is the only thing each part may assume about the
others. If something here is wrong, say so and stop — do not negotiate it in
code.

Owner: the lead. Do not edit this file without the lead.

## 1. The bake (`scripts/bake-intro.mjs` → `web/public/intro/`)

Three files, all deterministic (same release in, byte-identical out):

### `dots.bin`

Little-endian, no header, `N` records of **7 × float32 (28 bytes)**:

| #    | field    | meaning                                                                                                   |
| ---- | -------- | --------------------------------------------------------------------------------------------------------- |
| 0    | `w`      | weight, normalised 0..1 against the largest holding in the pair                                           |
| 1, 2 | `vx, vy` | dot position inside the VTI letters, in **em units**, origin at the text baseline's left edge, **y down** |
| 3, 4 | `ox, oy` | same for VOO's letters; **NaN, NaN** if the company is not in VOO                                         |
| 5, 6 | `rx, ry` | position on the final rule, in **em units of the ticker line**, same origin                               |

One record per company in the union of the two funds. Sorted by `company_id`
so the file is stable. float32, not float16: the difference is ~15 kB and it
removes a conversion layer from both sides.

### `caption.json`

```ts
{
  schema: 1,
  release: string,          // as_of of the release the bake read
  generated_at: string,
  a: { ticker, name, filed_at, as_of, companies },   // VTI
  b: { ticker, name, filed_at, as_of, companies },   // VOO
  shared: number,           // k, companies in both
  labels: [{ name, ticker, weight, index }],   // the 12 largest in `a`, weight desc;
                                               // `index` is the record index in dots.bin
  metrics: {
    unitsPerEm: number,
    a: { advance: number, ascender: number, descender: number },  // em units of the word "VTI" at its own font size
    b: { advance: number, ascender: number, descender: number },
    rule: { width: number, y: number }                          // em units, the final rule inside the same box
  }
}
```

### `glyphs.json` (committed artifact, not derived at build time)

The letter outlines the sampler used, so a future session can see what the dot
positions mean without re-running font tooling:

```ts
{ unitsPerEm: number, letters: { V: Path[][], T: Path[][], I: Path[][], O: Path[][] } }
// Path = [x0, y0, x1, y1, ...] closed polygons in em units, y down
```

## 2. The renderer (`web/components/intro/dots.ts`)

```ts
export interface FieldData {
  count: number;
  /** Float32Array of 7*count, the same layout as dots.bin. */
  raw: Float32Array;
  metrics: Caption["metrics"];
}

export interface DotsField {
  readonly lite: boolean;
  /** Scan progress 0..1: dots inside the A letters become visible behind the bar. */
  setScan(p: number): void;
  /** 0..1: B's dots lift out of A and fly to B's letter positions. */
  setTwice(p: number): void;
  /** 0..1: everything collapses onto the rule. */
  setCollapse(p: number): void;
  /** Camera push, 0 = the establishing frame, 1 = closest. */
  setCamera(z: number): void;
  /** Glow strength, 0..1. */
  setGlow(g: number): void;
  /** Screen-space box the A word occupies, and the B word, in CSS pixels. */
  /** Em metrics of the word, so the shader can map em space into the box.
   *  `box.top` is the top of the em box, and y maps ((dotY + ascender) / (ascender + descender)). */
  setMetrics(advance: number, ascender: number, descender: number): void;
  /** Length of the twice beat in ms, so the 60 ms impact squash stays 60 ms. */
  setTwiceBeat(ms: number): void;
  /** Camera-local, untransformed CSS-pixel boxes. The film applies the pull-back as one
   *  CSS transform on a wrapper around both the DOM letters and this canvas. */
  setBoxes(a: Box, b: Box): void;
  resize(): void;
  /** Draws one frame. The film calls this from its own ticker. */
  render(): void;
  destroy(): void;
}

export interface Box {
  left: number;
  top: number;
  width: number;
  height: number;
}

/** Returns null when WebGL2 is unavailable, and the film then plays without dots. */
export function createDotsField(
  canvas: HTMLCanvasElement,
  data: FieldData,
): DotsField | null;
```

Rules for this module: no timers, no state beyond its uniforms; every method is
a setter, and `render()` is the only side effect. It must survive `setBoxes`
being called before the first frame and after `resize`. Colours come from CSS
custom properties read once at construction (`--intro-table`, `--intro-light`,
`--intro-dot`, `--intro-twice`) with the values from the brief as fallbacks.

## 3. The film (`web/components/intro/play.ts`)

```ts
export interface PlayOptions {
  /** True for a replay (U key or the knob): reads and writes no storage. */
  forced?: boolean;
  /** Called once, at the moment playback starts, so the gate can write the day. */
  onStart?: () => void;
}
export async function play(
  host: HTMLElement,
  opts?: PlayOptions,
): Promise<"done" | "skipped">;
```

The film owns: the DOM stage, the GSAP master timeline, the seven beats, the
caption/counter/margin note, Skip and Esc, `document.startViewTransition` for the
handoff, and restoring every element it touched. It never rejects. It never
removes `host` — `IntroCurtain` does that after the promise settles.

Timeline beats are addressed by name so the lead can review them:
`T("dark", 0)`, `T("ticker")`, `T("scan")`, `T("hold")`, `T("twice")`,
`T("lights")`, `T("handoff")`.

## 4. The gate (`web/lib/intro-session.ts`) — lead

`decideIntro(snapshot)` decides once per page load. Keys:
`unpackfund.intro.day` (local `YYYY-MM-DD`), `unpackfund.intro.session` (`"1"`),
legacy `unpackfund.intro.last` deleted on first run. Order and edge cases are in
the brief §"Decision, in order" and §"Edge cases".
